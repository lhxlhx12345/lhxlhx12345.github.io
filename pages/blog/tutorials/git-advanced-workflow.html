Git 高级工作流实战

2026-06-0810 分钟阅读
掌握 Git 高级工作流，让你的版本管理更高效、更规范。

一、Interactive Rebase

Interactive Rebase 允许你在合并前修改提交历史，整理提交信息，合并琐碎提交。

命令行
# 修改最近3条提交 git rebase -i HEAD~3 # 常用操作： # pick — 保留提交 # squash — 合并到前一条提交 # reword — 修改提交信息 # edit — 暂停，允许修改内容

二、Cherry-pick

选择性地将某个分支上的提交应用到当前分支，而不需要合并整个分支。

三、Worktree

同时检出多个分支到不同目录，无需频繁切换分支，适合并行开发。
